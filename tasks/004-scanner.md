# Task 004 — Multi-Timeframe Scanner

## Objective
Build the first deterministic market scanner.

## Timeframes
- 4H context
- 1H structure/momentum
- 15M execution regime

## Initial signals
- EMA structure
- Swing structure
- RSI
- ADX
- RVOL
- Volume
- Support/resistance

## Safety
Scanner produces candidates only.
It must never place orders.

## Acceptance
- Deterministic tests
- Explainable score
- Candidate rejection reasons
- No execution authority
